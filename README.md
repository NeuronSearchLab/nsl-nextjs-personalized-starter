# Next.js Personalized Content Starter

The four-part NeuronSearchLab quick start: sync a sample catalogue, track behaviour through a server-side proxy, request `homepage` recommendations, and render the ranking.

1. Install the NeuronSearchLab resource from Vercel Marketplace and connect it to this project.
2. Deploy. Vercel injects all four `NSL_*` values; no separate account or public secret is needed.
3. Open several Football stories, then refresh to see the ranking adapt.

For local development, copy `.env.example` to `.env.local` and use a server-side SDK credential from the NSL console.
